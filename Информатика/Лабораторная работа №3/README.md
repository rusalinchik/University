## Вариант 4

**Цель:** Разработать базу данных для управления информацией о заказанных
товарах, их количестве и ценах, а также для учета заказов и анализа продаж.

**Задание**

**1. Создание базы данных**

Создайте базу данных с именем order_management.

![](https://github.com/rusalinchik/University/blob/main/Информатика/Лабораторная%20работа%20№3/pictures/1.png?raw=true)

**2. Создание таблиц**

Создайте таблицу **products** для хранения информации о товарах:

* Поля: **id** (уникальный идентификатор товара), **name** (название товара), **price** (цена за единицу).

Создайте таблицу **orders** для учета заказов:

* Поля: **order_id** (уникальный идентификатор заказа), **order_date** (дата
  заказа).

Создайте таблицу **order_items** для хранения информации о заказанных
товарах:

* Поля: **order_item_id** (уникальный идентификатор позиции заказа),
  **order_id** (идентификатор заказа), **product_id** (идентификатор товара),
  **quantity** (количество единиц товара), **total_price** (итоговая цена за
  данное количество).

**3. Связи между таблицами**

* Установите связь между таблицами **order_items** и **orders** через внешний ключ **order_id**, чтобы каждая позиция заказа была связана с конкретным заказом.
* Установите связь между таблицами **order_items** и **products** через внешний ключ **product_id**, чтобы каждая позиция заказа была связана с конкретным товаром.

**4. Добавление данных**

* Заполните таблицу **products** данными о нескольких товарах, включая
  названия и цены за единицу.
* Заполните таблицу **orders** несколькими заказами с указанием дат.
* Заполните таблицу **order_items** данными о заказанных товарах, указав
  количество единиц и рассчитанную итоговую цену для каждой позиции.

**5. Запросы**

* Напишите SQL-запрос для получения списка всех товаров с их ценами.
* Напишите SQL-запрос для получения всех позиций заказа по определенному
  заказу, включая названия товаров и их количество. (В коде пример с заказом №1)
* Напишите SQL-запрос для расчета общей стоимости всех товаров в
  конкретном заказе. (В коде пример с заказом №1)
* Напишите SQL-запрос для получения списка всех заказов за определенный
  период с указанием общей суммы.(В примере указан период с 01.06.2025 - 31.12.2025)

**6. Дополнительное задание**

* Реализуйте отчет о том, какие товары были заказаны чаще всего за
  определенный период
  .
* Напишите запрос для обновления цены товара по его идентификатору. (В коде пример с 3 товаром)
* Создайте запрос для удаления позиции заказа, при этом проверьте, что
  удаление не затрагивает другие данные. (В коде пример со 2 товаром)

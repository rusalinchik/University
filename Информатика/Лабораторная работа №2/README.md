## Лаборатораня работа №2
#### Вариант 4

**Задача 1: Создание и работа с файлами**

Условие: Создайте скрипт create_report.sh, который:
1. Создает файл report.txt
2. Записывает в него текущую дату и время
3. Считывает содержимое файла и выводит его на экран

Используемые команды: date, echo, cat, touch

**Задача 2: Циклы и условия**

Условие: Создайте скрипт even_numbers.sh, который:
1. Выводит все четные числа от 1 до 20, используя цикл
2. Если число четное, выводите его на экран

Используемые конструкции: for, if

**Задача 3: Аргументы командной строки**

Условие: Создайте скрипт multiply.sh, который:
1. Принимает два числа в качестве аргументов
2. Умножает их и выводит результат

Используемые конструкции: $1, $2, $(( ))

**Задача 4: Работа с процессами**

Условие: Создайте скрипт running_processes.sh, который:
1. Использует команду ps для отображения всех запущенных процессов
2. Выводит количество процессов, запущенных в данный момент

Используемые команды: ps, wc

**Задача 5: Работа с сокетами**

Условие: Создайте сервер и клиент, которые:
1. Сервер принимает сообщения от клиента и отправляет ответ "Сообщение
получено"
2. Клиент отправляет сообщение серверу и отображает ответ
Используемые команды: nc

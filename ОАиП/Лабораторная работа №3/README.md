## Лабораторная работа №3
#### Вариант 4

**Задание**

**1. Создание и заполнение данными файла**

Создайте программу, которая позволяет пользователю вводить данные о
заказанных товарах (название товара, количество единиц, цена за единицу) и
сохранять их в текстовом файле **"orders.txt"**.
Пользователь может продолжать добавлять данные о новых товарах, пока не
введет пустую строку в качестве названия товара.

**2. Поиск и сортировка в файле**
Реализуйте функцию для поиска товара по названию в файле **"orders.txt"**.
Пользователь вводит название товара, и программа выводит информацию о
найденном товаре.
Реализуйте функцию для сортировки товаров. Пользователь выбирает
критерий сортировки — по названию товара, количеству или цене за
единицу.

**3. Добавление данных в файл**

Напишите функцию, которая добавляет новый товар в конец файла
**"orders.txt"**.
Пользователь вводит информацию о новом товаре, и она добавляется в файл.

**4. Вывод данных по запросу пользователя**

Реализуйте функцию, которая принимает запрос пользователя и выводит
информацию о товарах из файла. Например, можно запрашивать товары,
цена за единицу которых не превышает введенное значение.

**5. Создание меню**

Создайте текстовое меню, в котором пользователь может выбирать команды
для добавления, поиска, сортировки и вывода данных о товарах.
Результаты каждой операции сохраняются в файл **"output.txt"**.
